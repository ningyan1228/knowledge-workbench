# 页面结构实施与验证 · 2026-11-17

依据用户提供的《工作台页面结构改进建议》，保留今日待办、客户开发、客户跟进、产品资料与更多工具的精简导航。

## 本次变化

- 客户库默认密表，50 家分页，卡片与地图保留。筛选后选择首条并同步详情；编辑未保存时保留离开确认。排序统一入口，来源与核验支持搜索、产品筛选、分批查看。
- 团队台账使用密表和可点击的今天到期、已逾期、待核实统计。负责人可记录实际跟进或推迟；读者与历史版只读。
- 操作保存在私有 SQLite 的 `followup_actions`，按台账版本与客户 ID 归属。使用幂等 UUID、最近操作校验与当前版本校验，发生冲突要求刷新。保留操作人、日期、说明及时间；不覆盖原 Markdown、下载字节或发送台账。新版不会自动继承旧版操作，以免旧完成状态盖过新任务。
- 参数与含义集中一张表；来源指向学习手册，缺失的核验人/日期标为未记录。未核验与存疑依据原状态区分，不作虚假审批。
- Ctrl/⌘K 支持产品参数、公司名和公开联系人。私人客户与联系人使用受权限保护的团队台账搜索；不进入公共构建。
- 行业分类筛选生效，回复助手本页可选产品，联网功能明确未接入。邮箱实时格式校验，学习问题空查询不再重复完整课程。
