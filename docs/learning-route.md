# 外贸学习路线（二期）

## 课程与路由

前端将原“外贸实务”入口升级为“外贸学习”，同时保留 Hash 路由 `#/practice`。课程页可直接访问：`#/practice/lessons/L01` 至 `#/practice/lessons/L40`；另外还有 `#/practice/questions`、`#/practice/review` 与 `#/practice/attempts`。旧外部链接如使用 `#/learning/...`，也会被兼容地打开学习页。

课程正文保存在 `src/lib/learningContent.ts`，共 8 阶段、40 节。这是版本化教学材料，不依赖 AI，也不使用真实产品的私有文档。每节均含学习目标、解释、教学情境、操作步骤、常见误区、术语、练习、自查和来源/适用边界。系统不会自动向客户、工厂或任何外部收件人发送内容。

L03、L08、L11、L39 分别覆盖文件匹配、缺口询盘、精确单位换算和完整模拟订单；L11 明确规定未知密度时不得把 mL 换算为 kg。

## 私人数据与完成规则

执行迁移 `supabase/migrations/202609240007_learning_route.sql` 后，以下内容通过 RLS 只对当前登录账户可见：学习计划、进度、练习答案、笔记、复习项目/事件、学习问题。

- 仅打开课程不会完成。
- “确认已读”只记录阅读；“提交练习”只记录作答。
- 两者均存在时，课程才变为 `completed`。
- 掌握度为 `unassessed`、`needs_review`、`confident`，与课程完成状态独立。
- 新复习项目默认次日；不会为 +1 天，模糊为 +3 天，会按 3/7/14/30 天递进。事件有幂等键，系统不自动补刷或重置。

可选关联一个已存在的私人产品；课程正文不会读取、展示或导出该产品的私有原文。导出功能仅导出当前用户的计划、进度、笔记、练习、复习事件和问题。

## 上线后的人工验证

1. 在 Supabase SQL Editor 执行第 007 迁移，确认没有错误。
2. 登录网站，打开“外贸学习”，选择起点、15/30/60 分钟和可选产品，保存计划。
3. 打开 L03、L08、L11、L39，确认每节都展示教学情境、参考答案和边界说明；L11 应显示 `USD 3.065/kg`。
4. 对任意课程先点“确认已读”、再提交练习，并刷新页面，确认状态为已完成且“我的练习”有记录。
5. 将一节课加入复习，次日或在测试环境调整日期后，对“不会/模糊/会”分别验证下次日期。
6. 导出 JSON，检查只包含当前登录账户的数据；退出并换账户后，不应看到前一账户的练习或笔记。
