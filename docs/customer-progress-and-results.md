# 客户进展与结果比较

入口：客户开发 → 开发结果。客户详情 → 我的开发进度与跟进 → 业务进展与原始反馈，也可逐家公司记录。

- 今日跟进清单按北京时间展示到期及逾期计划，按计划日期排列，每家公司一次。选择公司可安排下一步；不填日期表示暂不列入到期清单。
- 每次进展记录实际发生日期、原始反馈/依据、下一步和可选跟进日期。支持联系、回复、技术沟通、寄样、评估、测试反馈、报价、订单、暂停、拒绝、不适合及恢复跟进。
- 每个结果独立统计；寄样不代表评估，报价不代表订单。恢复跟进解除暂停/拒绝/不适合的工作清单限制；保留全部历史。误记可撤销，当前计划需自行核对。
- 补录早于最新进展的历史不会覆盖当前计划。计划可单独调整；各阶段当时的下一步保留在历史记录中。
- 结果与计划使用既有当前账号私人记录存储，沿用账号权限；共享邮件发送记录仅用于统计实际联系，不被改写。新字段为可选，旧记录继续可读。
- 按产品、地区、首次联系批次比较公司级结果；跨产品公司可能出现在多个产品组，不能据此推断具体产品已得到回复。
- 按实际应用和功能表达比较时，只使用每条进展中明确填写的归属。填写功能表达前须核对实际使用内容；提供当前材料功能作为可核对的输入提示，不自动归属历史记录。
- 回复比例只计算同归属中明确记录“已联系”的公司及其中有回复记录的公司。共享历史发送未注明归属，不自动计入该分母；未能核对分母时显示破折号。少于10家显示样本不足。
- 方向比较按技术沟通、样品评估公司数排序，仅作研究线索，不作采购概率、性能证明或因果效果判断。私有记录或共享发送记录不可用时统计显示不可用，不显示虚假的零。
