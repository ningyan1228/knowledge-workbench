# 验收报告（2026-09-19）

## 已完成的代码与本地验证

- React + TypeScript + Vite 静态前端：中文默认界面、Hash 路由、深色模式、移动端导航、loading/empty/configuration-safe 状态。
- 三个产品专题的初始化清单：全部明确为“原始文件待上传 / 待确认”，不创建假原文链接，不编造 NL 牌号。
- SQL 迁移：产品、版本、文件、段落、规格、声明、来源、文章、草稿、会话、任务、用量等表；RLS、Storage 私有策略、归属触发器、中文 trigram 搜索索引、幂等任务和租约 RPC。
- FastAPI 代理：JWT 的签名、签发者、audience、有效期验证；稳定错误码；未配置 AI 时安全降级。
- worker：PDF/DOCX 文本与定位提取、20MB 限制、扫描件 `needs_ocr` 状态、SSRF 拒绝、重定向复检、任务重试/租约、来源适配器。
- 真实公开端点适配检查：OpenAlex 和两个 Crossref 检索端点均实际提取到标题、日期或日期未知、摘要长度与 DOI 链接；见 `docs/source-catalog.md`。此项不代表文章已写入用户数据库。
- 前端生产构建：`pnpm build` 已通过（Vite 8.3.0；1,612 个模块；产物不含产品附件）。
- 前端安全规则测试：`pnpm test` 已通过（2/2），覆盖“未批准声明不能对外使用”与“证据不足时不伪造引用”。
- 视觉检查：本地预览在 320px 移动宽度和 1440×900 桌面宽度下均可打开；桌面左侧导航/卡片网格和移动端收起导航均正常，浏览器控制台无错误。

- AI 提供商、预算预留与真实摘要；目前未配置任何密钥，也没有伪造成功记录。
- Python worker 依赖与语法：已在工作区的隔离 `.venv` 安装锁定依赖；proxy/worker 导入及语法检查通过。尚未连接 Supabase，不能运行真实 job。
