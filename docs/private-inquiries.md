# 询盘往来

入口：`#inquiries`。沿用私人资料库登录，同一账号共用数据，不新增密码或用户。

## 存储与权限

- `inquiry_imports` 保存用户指定源文与 SHA-256；`customer_inquiries` 保存字段及四段正文。
- 三张表（含状态审计）启用 RLS，仅 `owner_id=auth.uid()` 可读；匿名角色无表权限。仅登录本身不赋予其他账号读取权限。
- 客户端只有 SELECT 权限。状态由 `set_inquiry_status` RPC 更新；检查账号归属、版本号并保留状态事件。不能修改原文、翻译或归属。
- 无在线编辑、自动发送、邮箱接入、自动客户编号关联。复制不会改发送状态。
- 登出或切换账号会卸载内容组件，未完成读取会取消。询盘不写 localStorage、不进入全局公共搜索。

## 导入

执行 `supabase/migrations/202611170002_private_inquiries.sql` 初始化结构。私有种子文件在被 Git 忽略的 `private-imports/` 中；不得提交，也不得贴到公开 issue。

源文与转换数据必须逐段比对。原文缺失的主题、公司等字段保留为空，不以产品名称猜主题；日期不猜时区。初始 pending。导入按所属账号与源文 SHA 去重，重复执行不重置已发送状态。

## 验证

隔离 PostgreSQL 测试覆盖匿名拒绝、不同账号隔离、原文禁止修改、状态审计及旧版本写入拒绝。页面测试使用本地模拟接口，不向生产写测试询盘。发布范围只包含通用代码、通用迁移和测试，绝不包含真实询盘或源文件。
