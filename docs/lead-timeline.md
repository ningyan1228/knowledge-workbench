# 客户收录时间线

全球地图和线索库支持最近/最早收录排序、按首次收录日期筛选，以及每日新增收录计数。地图统计与产品、大洲、国家筛选联动；线索库统计与产品、搜索条件联动。

现有数据没有首次爬取日志。`leadFirstRecorded.json` 保存公司记录首次出现在 `src/lib/productMarketMap.ts` 的仓库提交时间与 SHA，界面明确称为“首次收录”，不能称为首次爬取时间。核验日期与联系人更新不影响首次收录时间。没有历史证据的记录显示“时间未记录”，不借用核验日期或构建日期。

每日数量只计当前保留的客户，不包含已排除/删除的历史记录，也不等于采集尝试数量、任务运行次数或全部发现数。0 家表示该日没有当前保留的新收录客户，不能据此断定采集没有运行。日期和时间统一使用 Asia/Shanghai。

Pages 工作流以 `fetch-depth: 0` 读取完整历史，并在每次构建前运行 `node scripts/update-lead-timeline.mjs`。新增公司发布时会自动记录首次提交时间；已有记录不会因重新核验而改日期。脚本可在本地用完整仓库路径恢复历史：`node scripts/update-lead-timeline.mjs <repo-path>`。
